# LMS Main Service (Learning Management System)

Добро пожаловать в репозиторий моего микросервиса для системы управления обучением (LMS). Это бэкенд-ядро, которое отвечает за управление курсами, главами (разделами) и уроками. Я спроектировал архитектуру с упором на производительность, модульность и чистый код.

## 🚀 Стек технологий

- **Язык:** Java 21
- **Фреймворк:** Spring Boot (Web, Data JPA, Validation)
- **База данных:** PostgreSQL 
- **Миграции БД:** Liquibase (переведен на XML-формат)
- **Маппинг:** MapStruct (для преобразования Entity <-> DTO)
- **Утилиты:** Lombok (снижение бойлерплейта, @SuperBuilder для базовых классов)
- **Документация API:** Swagger / OpenAPI 3 (springdoc-webmvc-ui)
- **Сборка:** Gradle

## 🏗 Ключевые архитектурные решения

В процессе самостоятельной разработки я применил ряд важных паттернов и подходов:

1. **JPA Auditing & BaseEntity:** 
   Я выделил общие поля (ID, дата создания, дата обновления) в родительский класс `BaseEntity` (помеченный аннотацией `@MappedSuperclass`). Spring JPA Auditing автоматически управляет этими полями при сохранении данных в базу. Отношения настроены с поддержкой `orphanRemoval = true` для обеспечения чистоты базы при удалении связанных сущностей.

2. **Оптимизация базы данных:** 
   Для борьбы с потенциальной проблемой N+1 запросов при LAZY-загрузке я активно использую `@EntityGraph` в репозиториях (например, в `CourseRepository`), чтобы вытягивать сразу связанные списки при необходимости одной транзакцией (Join Fetch). Кроме того, в Liquibase прописаны скрипты создания критически важных индексов (Foreign Keys).

3. **Global Exception Handling:** 
   Я написал универсальный перехватчик ошибок `@RestControllerAdvice`, который формирует "красивый" и предсказуемый JSON-ответ в едином формате. Он элегантно обрабатывает как бизнес-логику (`ResourceNotFoundException`), так и ошибки валидации входящих запросов от `@Valid`.

4. **Пагинация и Сортировка API:** 
   Стандартные CRUD-контроллеры не отдают 100 000 строк списком. Я внедрил `Pageable` на уровне сервисов и контроллеров, что позволяет получать данные (например, `Page<CourseDto>`) порционно.

`http://localhost:8080/swagger-ui/index.html`

## ⚙️ Как запустить локально

1. Склонируй репозиторий и перейди в папку с проектом.
2. Убедись, что на твоей машине запущена база данных **PostgreSQL**.
   Укажи параметры подключения (URL, username, password) в файле `src/main/resources/application.yml`.
3. Собери проект при помощи Gradle:
   ```bash
   ./gradlew build -x test
   ```
4. Запусти приложение:
   ```bash
   ./gradlew bootRun
   ```
   *Liquibase автоматически накатит все нужные миграции (`001-create-tables`, `002-insert-data`, `003-create-indexes`), так что вручную таблицы собирать не придется!*
